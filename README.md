# Cassandra Beauty

Site statique. Ouvrir `index.html`.

## Mettre en ligne (GitHub Pages)
1. Déposer tout le contenu de ce dossier à la racine du dépôt.
2. Settings → Pages → Source : "Deploy from a branch" → branche `main`, dossier `/ (root)`.
3. Attendre une minute : l'adresse s'affiche en haut de la page Pages.

## Pages
- index.html — accueil
- calendrier.html — fiche Calendrier de l'Avent
- teint.html — catégorie Le teint
- histoire.html — Notre histoire
- produits.html — tous les produits
